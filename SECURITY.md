# Security Policy

## Supported deployment

The currently deployed public portfolio on the default branch (`main`) is the supported version.

## Reporting a vulnerability

Please do not publish security vulnerabilities, exploit details, credentials, or sensitive personal information in public issues or discussions.

Report suspected vulnerabilities privately to:

- Email: mahdirahmati.it@gmail.com
- Subject: `[Security] Portfolio vulnerability report`

Include:
- The affected page, file, or component.
- A concise description of the issue and its potential impact.
- Reproduction steps or a minimal proof of concept, where safe.
- Any suggested mitigation.

Do not access, modify, or delete other people's data; do not disrupt the public website; and do not test beyond what is necessary to demonstrate the issue.

A report is not an authorization to perform intrusive testing. Please allow time for assessment and remediation before public disclosure.

## Scope

This policy covers the source code and public deployment of this portfolio repository. Third-party services and infrastructure are governed by their respective security policies.
